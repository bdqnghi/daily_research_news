- **DAIR.AI** — DAIR.AI highlights an Amazon paper, CompoundingKernel, which reports writing GPU kernels from scratch with 1,000+ agents: 235 problems with verified kernels, first place on SOL-ExecBench public L1/L2/Quantization boards on B200, 4.40x over baseline; an LLM controller over an external archive beat UCB tree search on 35 of 38 problems.
- **Saad Syed** — Saad Syed describes Tasks in Gemini (Task mode, powered by Gemini 4 Hydrogen) rolling out free in six countries, and says Google Cloud's Agent Compute Engine runs each Gemini task in its own hardware-isolated VM built for high-churn agentic workloads.
- **Rohan Paul** — Rohan Paul summarizes a Zhejiang University paper ('Actor, Judge, or Teacher?') reporting that a decision model (JEV) that completes only 42.9% of ALFWorld tasks as an actor can, as a hindsight step-level grader, raise another agent's success from 72.8% to 82.9%.
- **Together AI** — Says agent harnesses force the model to reread the whole session each step, and prefix caching keeps that fast only if the prompt prefix stays stable and the inference engine routes each turn back to the machine holding the cache; links a write-up by Zain Hasan (Together) and Parth Sareen (Ollama) on what harness and engine each need to get right.
